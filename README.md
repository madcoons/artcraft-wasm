# artcraft-wasm

ArtCraft's open-source tools compiled to WebAssembly and packaged for npm. Each package lives in its own folder
and is released from tags named after it.

> **Unofficial.** This is independent packaging; it isn't made or endorsed by the ArtCraft or PhotoCraft authors.

| Package | Folder | What it is |
|---|---|---|
| `@madcoons/photocraft-wasm` | [photocraft](photocraft) | The [PhotoCraft](https://github.com/storytold/photocraft) image engine: open a file, run engine commands, read the composite |

Packages are attached to [GitHub releases](https://github.com/madcoons/artcraft-wasm/releases) as `.tgz` files;
install one by its release URL. See each package's README for its API, versions and how to release it.
